# Security Policy

## Supported Versions

Security fixes are provided for the latest version of Oriel OTP. Older releases may also be affected, and upgrading to the latest release is recommended.

| Version | Supported |
| --- | --- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Use GitHub's private vulnerability reporting for this repository:

[Report a vulnerability privately](https://github.com/SINF-KEN/oriel-otp/security/advisories/new)

If private reporting is unavailable, open a public issue asking for a private security contact. Do not include exploit details, credentials, OTP seeds, recovery codes, or other sensitive information in that issue.

When reporting a vulnerability, please include as much of the following as you can safely share:

- A clear description of the vulnerability and its potential impact.
- The affected version, platform, and relevant configuration.
- Steps to reproduce the issue, including a minimal proof of concept where possible.
- Relevant logs or screenshots, after removing secrets and personal data.
- Whether the issue is known to be actively exploited, if you have evidence of this.

Please avoid accessing, modifying, or deleting other people's data, disrupting services, or testing against accounts or devices you do not own or have permission to assess. Use test accounts and test credentials wherever possible.

## What to Expect

I will review reports as soon as practical and may ask for additional information to understand or reproduce the issue. Please do not assume a specific response or remediation timeline unless one is agreed with you directly.

Please keep the report and technical details private while the issue is being investigated. We can coordinate public disclosure after the issue is understood and, where appropriate, a fix or mitigation is available.

## Scope

This policy covers security vulnerabilities in Oriel OTP and the code maintained in this repository. Issues in third-party services or dependencies should be reported to their respective maintainers when they are not caused by Oriel OTP's integration.

Thank you for helping keep Oriel OTP and its users secure.
